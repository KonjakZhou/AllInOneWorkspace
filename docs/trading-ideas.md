# 交易灵感

在组件库添加「交易灵感」即可开始采集。卡片显示北京时间当天首次收录的数量，按发布时间从新到旧浏览全部已收录的交易灵感。发布时间不明确的条目按收录日期排序。上下滚动读取本地资料，底部显示上次成功采集时间。点条目在当前 App 窗口进入详情页并定位，点「查看全部」默认打开全部历史。页面左上角可返回工作区，回到原来的滚动位置。详情页的「按日看」按来源所给的发布日期汇总，默认从前一天开始。只有月份或年份的日期保留原有精度，可从全部历史找到。

在详情页添加原文链接，或为已有条目标优先级、添加研究问题和笔记。给不同条目填写相同的关联事件名称，就能从详情相互跳转。证据标记留有历史。将传闻标记为已澄清时，可以把澄清来源另收一条并关联，供日后核对。论文的「迁移候选」由市场和主题关键词初筛，表示值得看原文确认。论文收录时保留较完整的来源摘要。打开旧论文时，如果手头只有短摘录，应用会自动向原站尝试读取更长的匹配摘要。

## 来源和调度

自动收录集中于有交易方法、信号或可检验假设的论文和社区内容。纯行情快讯、新闻和常规公告不进入列表。已有的这类自动收录条目从视图隐藏，资料库保留原条目和个人记录。手动收录用于保存已经形成研究思路的材料。

| 类别     | 自动来源                       | 读取范围                                                                                                        |
| -------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| 公开社区 | 集思录 ETF 话题                | 公开话题页最近有回复的帖子。每轮最多读取 8 个详情，其余最多保留 16 个标题。仅在详情提供发帖时间时按发布日期归档 |
| 论文     | arXiv 量化金融、RePEc 金融市场 | 当前 RSS。按 arXiv ID 合并版本和明确的 RePEc 转引，保留工作论文的日期精度                                       |

每天北京时间 06:00 采集。只要 App 进程继续运行，关闭窗口后仍会采集。睡眠、退出或断网后按来源可提供的近期内容补抓。手动刷新复用正在进行的任务，遵守来源给出的等待时间。公开 RSS 和公告栏目在支持时使用条件请求。部分补抓失败会显示原因并保留已读内容。

## 资料库

应用数据目录下的 `trading-ideas/archive.sqlite` 保存标题、简短摘要、出处、日期和个人注释。`archive.sqlite.bak` 是最近一次完整 SQLite 快照。账号间共享公开来源历史，各自保存手动条目、关联事件及个人笔记。工作区 JSON 导出包含卡片配置，资料库使用独立备份。首次采集时间便于区分当天可见的信息和后来补录的资料。

## 试采

从首个交易日连续运行到第十个交易日次日 06:00，期间周末和节假日照常采集。在「采集状态 → 最近采集记录」查看逐源新增、失败及补抓限制；在「待研究」查看实际保留的条目。试采期间也可以手动收录公众号、视频、券商研报和播客样本，以比较是否值得后续接入。
