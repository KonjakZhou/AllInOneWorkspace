# 财联社 7×24 数据源与刷新

“财联社 7×24”卡片展示财联社公开电报流。每条摘要前显示消息等级。重点依据上游返回的推荐、推送、加粗及 A/B 级标记归一化。“重点”视图省略每条消息旁的重复标签。点击标题可展开正文，“打开财联社原文”由主进程按数字文章 ID 构造官网详情页。

## 刷新规则

- 卡片首次出现时读取最近 50 条。
- 卡片在视口内且应用处于前台时，每 30 秒检查一次。
- 窗口重新聚焦、卡片重新进入视口或 Mac 从睡眠恢复时立即检查缓存新鲜度。
- 浏览历史时，向下滚动读取更早的快讯，向上滚动自动补入相邻的较新快讯。悬浮在列表上方的「回到最新」可直接返回最新位置，按钮也显示待查看的快讯数量。
- 已在最新页顶部时，下拉刷新区域随手势展开。显示「松手刷新快讯」后松手，或停止滚轮和触控板滚动，即可刷新。底部刷新按钮也能主动检查最新数据。连续主动刷新仍受 5 秒请求间隔保护。
- 历史向上、向下和自动补页均先复用内存，再查磁盘，缺少可用页面时才按时间游标请求财联社，每页最多 50 条。全部和重点视图都以筛选后的行高判断是否要补页，跨过短页和无匹配页，直到填满卡片、达到源数据末尾或遇到请求错误。遇到错误时可按原游标重试。
- 卡片离开视口或应用隐藏时暂停周期读取和自动补页，返回时重新检查最新数据。

## 缓存与清理

- 内存中共享最新一页及最多 4 个近期历史页，历史页闲置 5 分钟后释放。每张卡片按筛选后条目数保留浏览窗口，常规尺寸最多 150 条，超高卡片按视口适当扩大。已离开浏览窗口的页面保留时间游标，正文由共享缓存按需读取。卡片连续 15 分钟不可见后释放已加载内容及浏览游标，共享最新数据闲置 15 分钟也会释放。
- 磁盘历史缓存位于应用数据目录的 `cache/cls-telegraph-v1`，用于复用已翻过的页面。缓存最多 128 页、16 MiB，超过上限时回收最近最少使用的页面，24 小时未读写的磁盘页会过期。应用启动、运行期间每小时以及写入时会检查并清理。
- 工作区保存卡片实例身份、版本、布局与“全部/重点”配置，组件 `data` 为 `null`。历史磁盘缓存独立于工作区保存、备份和账号导出，最新流从财联社读取。

## 数据源边界

主进程访问财联社网页使用的公开接口：

```text
https://www.cls.cn/v1/roll/get_roll_list
```

请求参数在本地按 key 排序后拼接，签名为 `md5(sha1(query))`，不需要用户账号、Cookie 或 API Key。渲染进程不直接联网，也不能把请求改到其他主机。

该接口公开可访问，但不是面向第三方的正式稳定 API。财联社可能调整路径、参数、签名或字段；发生不兼容时，卡片会保留已有内存内容并显示错误，不会静默混入东方财富等其他媒体的数据。维护时应先更新主进程客户端和响应校验，再发布新版本。

卡片保留“财联社”来源标识并提供官网原文入口。刷新间隔只代表本应用检查频率，不承诺财联社发布端本身没有延迟。
