# 自动更新与发布

从 1.1.0 开始，应用跟随公开仓库 `KonjakZhou/AllInOneWorkspace` 的正式 GitHub Release。普通提交、草稿和预发布版不会触发更新。不需要 Apple 开发者会员、付费证书或额外服务器。

## 使用更新

工作区右上角常驻“应用更新”按钮，点击可打开“版本与更新”窗口，手动检查或关闭“自动检查并下载更新”；原有“应用设置 → 应用更新”入口也保留。默认启动 10 秒后检查，之后每 6 小时检查；设备唤醒时只在缓存过期后检查。同一时间只进行一次检查或下载，手动检查至少间隔 60 秒。失败按 15 分钟、1 小时、6 小时退避，并遵守 GitHub 的更长限流期限。

发现新版后，右上角入口显示“有新版”；下载中显示进度，下载完成后显示“可安装”（当前目录不支持自动替换时显示“已下载”），并出现顶部提醒。关闭提醒后，右上角入口及状态仍然保留，可随时重新打开并选择“重启并安装”。没有新版时不会显示下载完成提醒；1.0.0 不包含这些入口。普通退出不会自动安装。关闭自动更新停止后续自动检查与下载，已经开始的下载允许完成。

自动替换支持 macOS 13+、Apple Silicon，以及以下两个**当前用户可写**的位置：

- `~/Applications/All In One Workspace.app`
- `/Applications/All In One Workspace.app`

在源码的 `release/`、下载目录、DMG 或不可写目录中运行时，可以检查和下载，但需打开发布页手动安装；应用不请求管理员权限。应用目录及其父目录均需可写，不接受逃逸的符号链接。Intel 尚未加入此次更新支持。

**1.0.0 没有更新器，必须手动安装 1.1.0 一次。** 把 App 放入上述目录后启动即可。账号、飞书凭据仍保存在原来的用户数据目录；不需要重新导入账号。

更新包使用本项目独立的 Ed25519 签名和 SHA-256 校验，这不等于 Apple Developer ID 签名或公证。macOS 可能要求在“系统设置 → 隐私与安全性”确认打开可信应用，也可能受设备管理策略限制。应用不会关闭 Gatekeeper 或清除 quarantine。请勿将本机测试通过理解为所有设备均无需安全确认。

## 发布应用

开发 agent 和维护者请阅读仓库根目录的 [RELEASING.md](../RELEASING.md)。发布身份、签名密钥、构建验证、版本标签、草稿上传和正式发布步骤统一在那里维护。

## 安装与恢复边界

安装前暂停编辑并保存所有已提交的工作区修改。保存失败时留在当前 App，修复后可以重试。

主进程验证签名、大小、SHA-256、ZIP 路径、符号链接、展开大小、平台和系统版本。原生助手使用编译时内置公钥再次验证清单和 ZIP，然后在目标目录旁准备新版。原进程退出后使用文件系统原子交换替换 App，通过 macOS 启动服务打开新版。

新版主进程在注册工作区服务、读取或迁移账号数据前与助手确认启动；只有安装事务提交后才打开工作区。替换或早期启动失败会尝试恢复并启动旧版。**确认启动并开始读取数据后，不自动降级**，以免新版数据迁移与旧代码不兼容。

如果系统阻止启动、文件系统不支持原子交换，或恢复步骤本身失败，查看更新设置中的失败原因并手动安装。异常中断的事务记录位于用户数据目录 `cache/app-updates-v1/.../install-<UUID>/status.json`；若旧 App 尚需恢复，它留在原安装目录旁的 `.aio-update-<UUID>/All In One Workspace.app`。先关闭相关 App，再确认版本后进行人工恢复。不要直接删除不明状态的暂存目录。

## 数据与缓存

- `update-settings.json` 是应用全局设置，账号切换不改变它，也不进入账号导出。
- 缓存在用户数据目录 `cache/app-updates-v1/KonjakZhou-AllInOneWorkspace-stable-darwin-arm64/`。先使用有效内存和磁盘数据；检查记录不超过 64 KiB，正常有效期 6 小时。
- 同时仅保留一个 ZIP，最多 1 GiB；展开内容最多 3 GiB、100,000 项。下载中断的片段在下一次初始化时删除，重试重新下载，不使用未经验证的断点内容。
- 应用升级或缓存闲置超过 7 天后，下次初始化清理旧包。完成或失败的安装日志保留 7 天；不自动删除可能需要人工恢复的安装暂存 App。
- 更新器不读取账号导出、飞书密钥或日程内容，不向 GitHub 发送它们。GitHub 连接仍会涉及普通网络请求的 IP 和应用 User-Agent。
